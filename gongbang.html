2주문서 ① 기본 틀

캔버스로 책 만들기 앱을 만들어 줘. 이름은 하이디 공방. A5 크기 책 페이지를 한 장씩 보여 주고, 위에 표지 만들기, 글 등록, 이미지 등록, 목차, 저장, PDF로 저장 버튼을 크게 넣어 줘. 글을 등록하면 새 장이 새 페이지에서 시작하게 해 줘.
🔍 더 자세한 주문서 (선택)

앱이 너무 단순하게 나오거나 버튼이 빠졌으면, 이 글을 같은 대화창에 이어서 보내요.

캔버스로 '하이디 공방 — 나만의 책 만들기' 앱을 만들어 줘. HTML 파일 하나로 만들어 줘. - 위쪽에 큰 버튼: [표지 만들기] [글 등록] [이미지 등록] [목차] [저장] [PDF로 저장] - 가운데에 A5 크기(148×210mm) 책 페이지를 한 장씩 보여 주고, [◀ 이전 쪽] [다음 쪽 ▶] 버튼과 쪽수를 표시해 줘. - [글 등록]을 누르면 '장 제목'과 '본문'을 쓰는 창이 열린다. 등록하면 새 장은 새 페이지에서 시작하고, 글이 길면 다음 페이지로 자동으로 넘긴다. - 어르신이 쓰기 쉽게 글씨와 버튼을 크게(버튼 높이 56px 이상), 쉬운 한국어로, 네이비와 하늘색으로 만들어 줘.

3주문서 ② 차례·사진·표지

⚠ 같은 대화창에 이어서 붙여 넣어요. 새 대화를 열면 처음부터 다시 만들어져요.
목차가 자동으로 만들어지게 하고, 사진 넣기와 표지 만들기, 고치기와 지우기 버튼을 넣어 줘. 있던 기능은 그대로 둬.
🔍 더 자세한 주문서 (선택)

앱이 너무 단순하게 나오거나 버튼이 빠졌으면, 이 글을 같은 대화창에 이어서 보내요.

지금 앱에 아래 기능을 추가해 줘. 있던 기능은 그대로 둬. - 목차: 글을 등록할 때마다 표지 다음 쪽 '차례'에 장 제목과 쪽수를 자동으로 넣는다. - 이미지 등록: 휴대폰 사진을 골라 지금 장의 끝에 넣는다. 크기(작게/중간/한 면 가득)와 사진 설명을 고를 수 있게. 사진은 자동으로 작게 줄여서 넣는다. - 표지: 책 제목, 지은이, 표지 사진을 넣는다. - 등록한 글과 사진마다 [고치기] [지우기] 버튼. 지울 때는 한 번 더 물어본다.

4주문서 ③ 저장·PDF

쓴 내용이 자동으로 저장되게 하고, 작업 파일 저장과 불러오기, PDF로 저장, 글자 크기 버튼을 넣어 줘. 있던 기능은 그대로 둬.
🔍 더 자세한 주문서 (선택)

앱이 너무 단순하게 나오거나 버튼이 빠졌으면, 이 글을 같은 대화창에 이어서 보내요.

지금 앱에 아래 기능을 추가해 줘. 있던 기능은 그대로 둬. - 쓴 내용은 자동으로 저장하고, 저장이 안 되는 화면이면 위쪽에 큰 글씨로 알려 준다. - [저장] 버튼: 책 전체를 '작업 파일'로 내려받고 다시 불러올 수 있게 한다. 내려받기가 막히면 내용을 복사해서 보관할 수 있게 한다. - [PDF로 저장]: A5 크기로 책 페이지만 PDF로 만든다. 인쇄 창이 안 열려도 PDF 파일을 바로 받을 수 있게 한다. - 본문 글자 크기를 [작게] [보통] [크게]로 바꾸는 버튼을 넣는다.
